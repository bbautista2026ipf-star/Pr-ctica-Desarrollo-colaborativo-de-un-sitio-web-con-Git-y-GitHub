## ¿De que se trata?

A traves de herramientas como HTML, CSS, GIT y GitHub. Desarrollamos un sitio web de caracter colaborativo gracias a la distribuicion y despues su fusion de ramas en GIT, migrado a GitHub.
La estructura de la pagina fue hecha gracias etiquetas HTML y una semantica determinada, Estilizada por CSS.

Nuestro sitio web se desarrolla desde la perspetiva de una cafeteria la cual se hace llamar "Cafeteria MARKITOS", presentamos una pagina de inicio con dos secciones, una descripcion de nuestros productos e indumentaria: el cafe.

## REFLEXION ★



# · ¿Qué ventaja encontraron al trabajar con Git y GitHub?


- Pudimos desarrollar correctamente la fusion de las ramas.
- Pudimos desarrollar distintas tareas sin interrumpir el desarrollo ajeno gracias a las ramas.
  <br> </br>

# · ¿Qué problema tuvieron al trabajar entre varias personas?

- Problemas con la coordinacion.
- Problemas con la fusion (Merge Conflict).
- Problemas con la curva de aprendizaje.
- Problemas con el mismo desarrollo del pie de pagina (footer) y encabezado (Header)

<br> </br>

# · ¿Por qué creen que usar ramas ayuda en un trabajo colaborativo?


- Permite el desarrollo colaborativo.
- Permite eficiencia a la hora de desarrollar nuevas funcionalidades en un proyecto sin arriesgar versiones anteriores.
- Permite coordinar y asignar determinadas tareas.
